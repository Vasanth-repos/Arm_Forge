ArmForge 6-Phase Optimization Pipeline Workflow

End-to-End Stacked Execution
PHASE 0 & 1

ISA Probing & Native Build

Probes /proc/cpuinfo for dotprod & i8mm features. Compiles llama.cpp with ARM vector flags.

PHASE 2 & 3

Quantization & Thread Tuning

Converts weights to Q4_K_M INT4. Runs thread sweep (1–4 threads) and binds NUMA memory via numactl.

PHASE 4

KleidiAI Matrix Kernels

Routes GEMM matrix multiplications through Arm KleidiAI micro-kernels with batching (-b 512) for +55.8% throughput.

PHASE 5

Speculative Drafting (3B+1B)

Pair Llama-3.2 3B verifier with 1B draft model for 72.5% acceptance rate and -44.0% TTFT latency reduction.

PHASE 6

Full Stacked Acceleration

Combines KleidiAI + Speculative + memory locking (--mlock) + core binding for peak 8.5 tok/s & 400ms TTFT.

PHASE 7

Live SSE Dashboard Server

Launches FastAPI dashboard with SSE stream endpoints on port 8080 and zero-cloud on-device playground.
